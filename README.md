# MATRIX / TETRIS

Одностраничный Тетрис на TypeScript и React в стиле фильма «Матрица»: тёмный терминальный интерфейс, зелёное свечение и падающие символы на фоне.

Игра работает полностью на фронтенде. Для игрового процесса не нужны сервер, база данных, учётная запись или ключи API.

## Возможности

- Начало, завершение и повторный запуск партии.
- Перемещение, поворот, ускоренное падение и мгновенный сброс фигур.
- Семь типов фигур и игровое поле 10 × 20 клеток.
- Очистка заполненных линий и начисление очков.
- Три режима сложности: **Новичок**, **Оператор**, **Избранный**.
- Повышение уровня и скорости после каждых 10 очищенных линий.
- Предпросмотр следующей фигуры и тень места приземления.
- Пауза и автоматическая остановка при скрытии вкладки.
- Сохранение рекорда в `localStorage`.
- Экранные кнопки для игры на телефоне.
- Отключение фоновой анимации при системной настройке уменьшения движения.

## Как играть

1. Выберите сложность до начала партии.
2. Нажмите **«Войти в Матрицу»** или `Enter`.
3. Собирайте горизонтальные линии без пробелов.
4. Не допускайте заполнения поля до места появления новых фигур.
5. Для досрочного завершения нажмите **«Выход»**.

Сложность нельзя менять во время партии, в том числе на паузе.

### Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `→` | Перемещение влево / вправо |
| `↑` | Поворот фигуры |
| `↓` | Ускоренное падение |
| `Пробел` | Мгновенный сброс вниз |
| `P` / `Esc` | Пауза / продолжение |
| `Enter` | Начало новой игры или продолжение с паузы |

На телефоне используйте экранные кнопки. Удерживание кнопок движения и ускорения повторяет действие.

### Очки

| Очищено линий одновременно | Базовые очки |
| --- | ---: |
| 1 | 100 |
| 2 | 300 |
| 3 | 500 |
| 4 | 800 |

Базовые очки умножаются на текущий уровень. Ускоренное падение добавляет 1 очко за клетку, мгновенный сброс — 2 очка за клетку.

## Запуск

Команды выполняются из корня репозитория.

### В Replit

Используйте настроенный процесс **`artifacts/matrix-tetris: web`**. Он передаёт приложению необходимые переменные `PORT` и `BASE_PATH`.

### Локально

Требуются Node.js 22+ и pnpm 10+.

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/matrix-tetris run dev
```

Откройте `http://localhost:5173`.

Примеры команд с переменными окружения приведены для Bash / Linux / macOS.

### Проверка TypeScript

```bash
pnpm --filter @workspace/matrix-tetris run typecheck
```

### Сборка

```bash
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/matrix-tetris run build
```

Результат сборки: `artifacts/matrix-tetris/dist/public/`.

Для локального просмотра собранной версии:

```bash
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/matrix-tetris run serve
```

### Переменные окружения

| Переменная | Назначение | Пример |
| --- | --- | --- |
| `PORT` | Порт сервера Vite; обязателен также при чтении конфигурации для сборки | `5173` |
| `BASE_PATH` | Базовый URL-путь приложения | `/` |

## Структура проекта

```text
artifacts/
  matrix-tetris/
    index.html                     # Метаданные страницы
    src/
      App.tsx                      # Точка входа интерфейса и маршрутизация
      index.css                    # Тема, оформление и анимации
      pages/Game.tsx               # Игровое поле и элементы управления
      game/
        engine.ts                  # Фигуры, столкновения, линии и очки
        useTetris.ts               # Состояние игры, таймер, клавиатура и рекорд
      components/matrix/
        MatrixRain.tsx             # Фоновый цифровой дождь
    vite.config.ts                 # Настройки сервера и сборки
  api-server/                      # Общий сервер шаблона; игре не требуется
  mockup-sandbox/                   # Среда предпросмотра компонентов
lib/                               # Общие библиотеки шаблона
```

## Хранение данных

Рекорд хранится только в текущем браузере под ключом `matrix-tetris-best`. Он не синхронизируется между устройствами и может исчезнуть после очистки данных сайта. Если браузер запрещает доступ к хранилищу, игра остаётся доступной, но рекорд не сохраняется между посещениями.

Текущая партия не сохраняется: после перезагрузки страницы нужно начать новую игру.
